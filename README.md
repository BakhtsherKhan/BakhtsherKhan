### About Me

I'm a PhD researcher at the **University of Science and Technology of China (USTC)**, working at the intersection of **cybersecurity, network security, and IoT security**. My research combines **reverse engineering, protocol analysis, and formal verification** to uncover security vulnerabilities in real-world secure messaging systems and IoT devices.

- PhD candidate in Cybersecurity at USTC, Hefei
- **Research interests:** Reverse engineering of secure messaging protocols, network security, IoT security, applied cryptography, formal verification
- **Currently working on:** Delivery integrity in server-mediated messaging systems
- **Ask me about:** Protocol reverse engineering, cryptographic analysis, IoT security, vulnerability discovery

---

### Research Focus

- **Reverse Engineering** — Analyzing closed-source secure messaging protocols to identify weaknesses and verify security claims
- **Network Security** — Protocol design, traffic analysis, secure communication
- **IoT Security** — Lightweight cryptography, device authentication, embedded security
- **Applied Cryptography** — Key exchange, encryption schemes, secure messaging
- **Formal Verification** — Proving security properties with tools like CryptoVerif, ProVerif, and Tamarin
- **Vulnerability Research** — Identifying and responsibly disclosing security flaws in deployed systems
